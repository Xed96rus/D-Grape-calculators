# Расчёты D-Grape

Инженерные калькуляторы к ВКР по роботу-опрыскивателю D-Grape для виноградника: система управления на основе VSLAM, стереокамеры, IMU и RTK GNSS.

Сайт: `https://Xed96rus.github.io/ИМЯ-РЕПОЗИТОРИЯ/`

## Страницы

| Файл | Что считает |
| --- | --- |
| `index.html` | Главная страница со ссылками на расчёты |
| `cameras.html` | Частота карт глубины, частота каждой камеры, выбор разрешения, базис стереопары, угол обзора камеры |
| `positioning.html` | Критерий допустимой ошибки, допустимый сдвиг центра, ошибка курса, допустимая ошибка одометрии |

Каждая страница — один самостоятельный HTML-файл без сборки и без сервера. Расчёты выполняются в браузере, введённые значения сохраняются в `localStorage`.

## Как обновить расчёт

1. Откройте нужный файл в репозитории и нажмите на значок карандаша, либо загрузите новую версию файла с тем же именем через **Add file → Upload files**.
2. Нажмите **Commit changes**.
3. Через минуту-две изменения появятся на сайте.
